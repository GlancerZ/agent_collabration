连接 Slack

在目标 workspace 创建两个应用，分别显示 Codex 和 Claude。主应用接收任务，两个应用分别发布各自 agent 的结果。

  1. 打开 Slack 应用控制台，选择 Create New App → From a manifest。
  2. 分别导入下方两个 manifest，并选择 你要使用的工作区。
  3. 在两个应用的 OAuth & Permissions 中分别 Install to Workspace，取得各自的 Bot User OAuth Token。
  4. 在 Codex 的 Basic Information → App-Level Tokens 中生成带 connections:write 权限的 App Token。
  5. 在你指定的频道里邀请两个 Bot。复制频道 ID 和你自己的 Member ID，填入右侧。
  6. 保存设置，再点击“连接 Slack”。Token 只保存在本机私有配置文件中，不会返回给网页。
